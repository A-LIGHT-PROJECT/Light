# Contributing to Light Builds project
If you're contributing to Light, here are some guidelines you need to know
- Make sure your contribution to Light is complete, not half-finished or almost done.
- If you're contributing to add some abstract flags, (1) add it to the SE_CODE list of enums and make a comment saying the amount of enums there is now. (2) Do not add any flags to it if it is commented 255, there will be a new section of enums. (3) If you add a flag, add a switch case inside the checkFileForTrans function.
- If you're contributing, pull requests will be reviewed thoroughly to see if your code is good to be merged together with Light. If it isn't, there will be an explanation for this rejection.
